# Edge Detection in Potential Field Data Using Wavelets

This repository contains MATLAB codes for detecting edges and geological boundaries in potential field data (magnetic or gravity) using various wavelet transforms.

## 🔹 Overview
The project starts from basic wavelets (Haar, Daubechies, Coiflet) and extends to more advanced and combined methods for improved boundary detection.

## 🔹 Methods Implemented
- Haar Wavelet Edge Detection  
- Daubechies (db2, db4, db8)  
- Symlet and Coiflet Wavelets  
- Continuous Wavelet Transform (CWT)  
- Multi-scale edge enhancement  
- Comparison of continuity index and localization error  

## 🔹 Data Type
- Potential field data (magnetic or gravity)
- Synthetic and real datasets

## 🔹 Output
The scripts generate:
- Edge maps for each wavelet type  
- Quantitative metrics (Continuity Index, False Edge Rate, Localization Error)
- Figures comparing performance of wavelet families
